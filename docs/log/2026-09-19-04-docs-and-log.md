## 为什么

- 结构和用途散在两个人的脑子里和 1000 行的 README 里，需要一个"查表用"的入口。
  `technique-system/README.md` 讲**为什么**，`docs/STRUCTURE.md` 讲**在哪**。
- 日志单独立一个文件夹的理由写在 `docs/log/README.md`：
  **一半的改动其实是决策**（"为什么不用引擎"、"为什么把整本账翻回来"），
  commit message 放不下，而它们恰恰是几个月后最需要的东西。
