# 重启服务器 + 清理垃圾 + 特效方案

- **日期**：2026-09-19
- **触发**：① 静态服务器进程被宿主的 job runner 杀掉（exit 1073807364）；
  ② 玩家要求"把该干的事干了，清理一下垃圾"；③ 玩家问技能特效谁做、怎么做
- **动了哪些文件**：删了 `.npm-cache/`（30.5 MB）；新增 `docs/vfx-plan.md`；
  `technique-system/README.md`（欠账指向方案）；本日志

## 改了什么

### 1. 重启静态服务器

`pwsh-1`（`node src/cli/serve.ts --port 5173`）被宿主杀掉，报的是
`Windows Job runner exited with exit code 1073807364 before proving its managed range empty`
—— 这是 job runner 自己的退出码，不是 serve.ts 崩了。

重新起了一个，验证过：`index.html` / `manifest.json` / `content/skills/*.json` /
`dist/.../main.js` / `dist/.../editor.js` 全部 200。
**http://127.0.0.1:5173/ 可以继续玩。**

### 2. 删掉项目里的 30.5 MB npm cache

`.npm-cache/` 是某次 npm 跑的时候把 cache 建在了项目里。
确认过 `npm config get cache` 指向 `%LOCALAPPDATA%\npm-cache`，
项目里这份**没人用**，直接删。删完 `npm test` / `npm run validate` 全绿。

顺手查了其它垃圾：没有 `.scratch/`、没有第一次构建失败的 `.js`/`.map` 残留、
工作区根目录下别的目录（chaoxing-auto / linkedlist-lab / mlg-water-bucket……）是玩家的其它项目，不碰。

### 3. 技能特效：先出方案，不动手

玩家的原话是"研究……是我做还是你做？怎么做？"——所以这一轮**只出方案**，
写在 [`../vfx-plan.md`](../vfx-plan.md)。

查出来的现状（比想象的严重）：

| 载体 | 谁在用 | 看得见吗 |
|---|---|---|
| `projectile` | 魔法飞弹 | ✅ |
| `beam` | **贯日、裂魂** | ❌ |
| `meleeArc` | **裂地斩** | ❌ |
| `area` | **熔岩护甲、无下限** | ❌ |

**六个用了载体的技能里，五个完全没有表现。** 贯日不是个例，是一整类载体没做。

还挖出两个更深的缺口：

- **`StatusDef.vfx` 是个死字段** —— schema 里有、内容里写了、**没有一行代码读它**
- **事件里没有"动作打出去了"** —— 15 种事件全是"结果"，所以打空了没有特效，
  而打空恰恰是最需要看得见的时刻

分工结论：**程序化特效（几何 + 颜色 + 时间）我做；美术资产和审美判断你做。**
现在**不要**做美术资产 —— 没有资源管线，塞一张 PNG 要连做三件事。

## 为什么

- 服务器是玩家唯一的可视化入口，它死了等于整个项目看不见了，优先级最高。
- cache 是纯垃圾，30 MB 换不来任何东西。
- 特效是**这一类**问题而不是一个技能的问题，所以要先定做法再动手 ——
  否则会变成"给贯日写一段特效代码"，那就又是一份会和内容漂移的真相。
