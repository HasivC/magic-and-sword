## 改了什么

### 1. 符号约定：这是一本「额度账」

```
负数 = 效果消耗的额度    正数 = 代价提供的额度
合计 = 0 配平；合计 < 0 = 花超了 = 超模 → 血契补
```

⚠ **这一条我改错过一次，玩家纠正了两次。**

> 玩家第一次：「买卖规则位得点数的正负反了。」
> 我理解成整本账反了 → 把"收益/代价"全部对调。
>
> 玩家第二次：「多出收益的不是超模技能，因为我已经付出代价了，
> **点数为负值的才是超模技能**。」

他第一次说的"反了"指的是**那一行** —— 账本里别的东西消耗额度都是负的，
唯独"买规则位"（同样是消耗额度）显示成 `+1.5`。
而我把整本账翻了过来，顺手把超模的判据也翻反了。

**教训：账本的方向是从玩家那一侧定的，不能因为一行看着别扭就整本翻。**
现在只改那一行。

（另一个佐证：编辑器 CSS 里绿色那条叫 `.gain`、红色叫 `.cost` ——
命名本来就是照"额度账"写的，所以改回来之后**颜色自己就对了**。）

### 2. 规则位档位改成 0..8

`[0,2,4,5,6,8]` → `[0,1,2,3,4,5,6,7,8]`。它是**条数**，
每一档都是一个不同的东西，跳档说不通。（9 档仍在"最多 10 个"以内。）

### 3. 三档打断等级

`Phase.interruptible: boolean` → `Phase.interrupt: 'damage' | 'control' | 'none'`

| 等级 | 意思 | 点数 |
|---|---|---|
| `damage`（默认） | 受到任何伤害都会断 | 0 |
| `control` | 挨打不断，被眩晕/沉默会断 | 半价收益 |
| `none` | 霸体帧，什么都不打断 | 全额收益 |

出厂内容里**释放帧用 `control`**（挥砍/贯通/飞弹/裂魂/无下限）——
近战被蹭一下就读条中断根本没法玩；收招和名刀常驻用 `none`。

**实现踩到的坑**：伤害在管线第 9 步结算，施法推进在第 5 步 —— 施法比伤害早。
想让"挨打就断"立刻反应，管线就得反过来 import 施法系统（循环依赖）。
所以伤害只在实体上留 `Entity.damagedTick`，施法那边比 `=== world.tick - 1`。

`world.tick - 1` 在**第 0 个 tick** 正好等于哨兵值 `-1` ——
少了 `>= 0` 这个判断，开局第一 tick 所有实体都被当成"刚挨过打"，
什么技能都放不出来。**21 条断言同时变红才定位到这一行。**

### 4. 冷却时机：前摇 / 释放 / 后摇

机制一直都有（代价在**进入阶段时**结算，而且**不退还**），缺的是把它讲出来。
原来面板写着「收招 · 冷却」，玩家看到的是"收招有个冷却"，
而不是"我选了在收招时才进冷却"。现在是一块独立的三选一 +
常驻说明「越靠前越先进冷却，但被打断就白付了」。

## 为什么

- 三档是**玩法需要**：只有"能/不能"两档时，"扛得住小伤害、但吃硬控"的释放帧
  表达不出来 —— 而那恰恰是动作格斗里最常见的那种帧。
- 冷却时机是**设计自由**：早进 CD 是收益，被打断白付是风险，这个取舍该由玩家做。
