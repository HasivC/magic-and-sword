# 撤掉「出厂就负债」那个标记：宗旨没有例外

- **日期**：2026-09-21
- **触发**：玩家看完上一轮（两个技能库）之后问：
  > 注意，**负债件的变体不一定是负债件**，它的那个标记有什么用处？我觉得没什么必要。
- **动了哪些文件**
  - 规格：`schema/skill-schema.ts`（删 `Skill.factoryDebt`，留墓碑注释）、`schema/README.md`
  - 引擎：`src/pricing.ts`（`skillLedger` 少一个分支）
  - 前端：`web/src/editor.ts`（去掉「负债件」标签和那块说明；点数说明改成"相对模板"）
  - 内容：`content/skills/{soul-rend,blood-offering}.json`（去掉标记）
  - 测试：`tests/{pricing,smoke,scenario}.ts`
  - 文档：`docs/glossary.md`、`docs/default-values.md`、`docs/STRUCTURE.md`

---

## 一、那个标记原来在干什么

它只有一个作用：**让出厂内容里也有"一放就吃血契"的技能**。

| 技能 | 它的绝对账 | 用它放一次（当时） |
| --- | --- | --- |
| 裂魂 | −4.73 | 4.73 血契 |
| 血祭斩 | −4.61 | 4.61 血契 |

它是 2026-09-21 上加的（切到"相对出厂值"的账之后，出厂内容全变 0，
血契就没有出厂消费者了）。**同一天撤掉** —— 玩家看完之后的判断是
"没什么必要"，两句话：

> **负债件的变体不一定是负债件。**
> （宗旨）应该是**铁的**。

## 二、玩家说得对，而且我实现得比它说的更糟

判据取的是**模板**（`base.factoryDebt`），所以变体**一定**继承 ——
不是"不一定"，是"永远"。后果很怪：

- 把裂魂改**弱**成一个变体 → 它的绝对账可能变**正** →
  用了这个变体的术式反而**拿到一大笔额度**，而算法还是"负债件"那一套（按绝对账算）。
- 把裂魂改**强** → 那个术式吃掉更多血契。

也就是说这个标记在变体上**既不表达"它是负债件"，也不表达"它不是"** ——
它只是把"模板的账"整段搬了过来。

## 三、删掉之后现在是什么样

- **宗旨没有例外**：任何技能在它自己的默认值下都是 0 点。
  `tests/pricing.ts` 新增一条**逐个扫内容**的断言（30 个技能全查），
  以后谁偷偷偏离，那里当场红。
- **出厂技能没有"债"可以继承**：一份原样的变体也是 0 点（也钉了一条断言）。
- **负值术式仍然存在，只是要自己编**：把变体改强 → 那份术式的合计变成负的 →
  一放就吃血契。`tests/scenario.ts` 的第 33 节（血契不够放不出来 / 刚好够 /
  差 0.01 也不行）现在就是这么造的 —— 它照着玩家真正会做的事跑一遍。
- **裂魂、血祭斩变成普通技能**：它们仍然有 20 秒冷却 / 40 能量 / 8 秒冷却
  这些代价，只是不再额外吃血契。
  ⚠ 玩家说**先不动内容**，所以：血祭斩的名字、介绍、还有它的「负值」标签，
  以及裂魂的「超模」标签，现在和机制**对不上了** —— 这两处文字欠着
  （见欠账）。我在两个技能的 JSON 里各留了一条 `_comment_debt_removed`
  把这件事写在原地，免得下一个人以为它们还是负债件。

## 四、为什么

一句话：**为两个出厂示范在宗旨上开一个口子，不值。**

而且"出厂内容能花超"这个能力，**玩家自己编一个变体就有了** ——
那才是血契要服务的东西（"攒很久、Boss 关一口气放掉"的是**他自己编的**超模术式）。
删掉之后：代码少一个分支、schema 少一个字段、编辑器少一块说明、
文档少一个例外、测试少一节，而**玩法一点没少**。

## 六、欠账

1. ⚠ **血祭斩的名字 / 介绍 / 「负值」标签，裂魂的「超模」标签** ——
   现在和机制对不上（它们不再是负值术式）。玩家说"先不动内容"，
   所以留着；最直白的改法是让血祭斩**真的扣自己的血**（"燃烧自己"落到机制上），
   或者把标签和介绍里的那两句改掉。
2. 技能修正（技能编辑器里管数值和几何）。
3. 修饰技能：术式的连接卡 + 触发器卡（触发器要引擎支持并行施法）。
4. 锚点表（`content/anchors.json`）：`calibrate` 的拟合目标仍然不成立。
5. 阶段时长的 无 / 1× / 3× / 9× 四档。
