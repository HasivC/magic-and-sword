# 各机制的**标准数值** —— 写内容时的**强度标尺**（草稿，等玩家改）

> 玩家 2026-09-21：
> > 所有点数相关的可调整的值，都具有一个默认值，在这个默认值下点数是配平为0的。
> > ……是按**技能**算。
> > （默认值从哪来）**每个技能自己定（内容里的就是默认）**
> > （这张表）**你先起草，我在上面改**

⚠ **先看清楚这张表是干什么的**（2026-09-21 追问之后定的）：

| | 谁定 | 参与算账吗 |
| --- | --- | --- |
| **每个技能的默认值** | 它自己的内容（`content/skills/*.json`） | **是。** 账 = 现在 − 出厂 |
| **这张表** | 作者（我起草、玩家改） | **否。** 它只是「一个标准技能该有多强」的参考 |

所以下面这些数字**不产生任何点数**。它们的作用是：

1. 我写新技能时有个统一的尺子 —— 不然后写的技能会越写越强（或越写越弱）。
2. 想给某个机制「定个价」时有个起点（比如「位移 6 米算标准，那 12 米该多贵」）。
3. 玩家看内容时能一眼看出「这个技能是超模还是保守」。

**判据仍然是那两条**：出厂技能在**它自己的数值**下是 0 点（宗旨）；
术式必须配平到 0。

---

## 一、这张表怎么用

- **机制本身免费**：一个技能「能位移」这件事不要钱（玩家原话：
  「位移的机制本身是不应该有代价的，位移的距离有代价」）。
- **数值有价**：**偏离出厂值**就进账 ——
  比出厂弱/慢/短 → 提供额度（正）；比出厂强/快/长 → 消耗额度（负）。
- 一个技能在**它自己的默认值**下，账必须是 **0** —— **没有例外**。
  （曾经有过一个 `factoryDebt`「出厂就负债」的例外，2026-09-21 撤掉了：
  宗旨是铁的，而且它在**变体**上说不通 —— 见日志 2026-09-26-33。）

## 二、草稿：各机制的标准数值（⚠ 这一节请你改）

### 载荷（干了什么）

| 机制 | 标准值 | 依据 |
| --- | --- | --- |
| 伤害 | **25 点** | 出厂内容里最多的是 25（魔法飞弹 / 猎杀 / 寒冰锁 / 冲击波） |
| 治疗 | **30 点** | 圣光术 |
| 改属性·当前值（能量/生命） | **15 点**（方向和大小分开算） | 扣 15 能量 ≈ 一发普通技能 |
| 改属性·倍率 | **×1.0** | 不改就是标准 |
| 挂状态·持续 | **3 秒** | 裂地斩的破甲 |
| 挂状态·层数 | **1 层** | |
| 位移·击退 / 拉拽 | **2 米** | 破军突刺 |
| 位移·冲刺 | **6 米** | 突进 |
| 位移·瞬移 | **2 米** | 瞬影 |
| 感知·标记 / 显形 | **3 秒** | |
| 召唤 | **1 个** | |

### 载体（怎么出去）

| 机制 | 标准值 | 依据 |
| --- | --- | --- |
| 近身扇形 | 半径 **2.5 米** / 张角 **120°** | `REACH_BASELINE`（已有） |
| 投射物 | 速度 **12 米/秒** / 寿命 **1.5 秒** | |
| 光束 / 突刺 | 长 **8 米** / 宽 **0.6 米** | |
| 区域 `area` | 半径 **6 米** | `AREA_BASELINE`（已有） |
| 光环 `aura` | 半径 **4 米** | 同上 |
| 屏障 | 长 **6 米** / 宽 **0.6 米** | 屏障那一轮定的 |

### 时间与代价

| 机制 | 标准值 | 说明 |
| --- | --- | --- |
| 前摇 | **0.3 秒** | 出厂内容里最常见 |
| 命中 | **0.2 秒** | |
| 后摇 | **0.2 秒** | |
| 打断等级 | **`damage`（挨打就断）** | 已经是「基准 = 0 点」（`control` / `none` 提供额度） |
| 能量代价 | **0**（不花） | 代价的中性点就是「不花」；花了 → 提供额度 |
| 冷却 | **0**（无冷却） | 同上 |
| 生命代价 | **0** | 同上 |
| 规则位 | **4 条**（`baseRuleSlots`） | 已经是「偏离基准才计价」 |

### 阶段时长的档位（玩家 2026-09-21 定的）

> 甚至可以是**无、1\*、3\*、9\***，因为玩家调这个可不是为了手感，而是**获取大量点数**。

| 档位 | 点数方向 | 意思 |
| --- | --- | --- |
| **无** | **消耗额度** | 瞬发（比标准快，是好处） |
| **1×（默认）** | **0** | 出厂那一档 |
| **3×** | 提供额度 | 慢三倍 = 一大笔额度 |
| **9×** | 提供很多额度 | 慢九倍 = 极大一笔额度 |

⚠ 倍率是**几何级数**，不是「±0.1 秒」那种微调 ——
玩家动这个滑块的目的**就是换点数**，所以档位之间要拉得开。

## 四、这张表里我拿不准的（请你顺手一起定）

⚠ 先说清楚：**下面这几条现在都不影响算账**（账是相对出厂值算的），
它们影响的是「我写的新技能该有多强」。所以它们不急，但越早定越好 ——
不定的话，后写的技能会慢慢和先写的对不上。

1. **伤害的标准值**：25（现在最常见的）还是 30？还是按类型分（物理 25 / 元素 20）？
2. **能量代价的标准值**：真的是「不花」吗？还是「一个普通技能默认花 10」？
3. **冷却的标准值**：真的是「无冷却」吗？—— 出厂内容里几乎每个技能都有 2~20 秒冷却。
4. **前摇/命中/后摇**的标准时长是不是应该**按机制分开**（打人的招适合 0.3/0.2/0.2，
   位移的招适合 0.1/0.1/0.1）？还是一律一套？
5. **倍率类数值**（伤害 ×2 这种技能修正）怎么计价 —— 按「偏离 1.0 的百分比」？
